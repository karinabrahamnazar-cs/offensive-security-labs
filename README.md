README.md# Offensive Security Labs 

Repositorio centralizado para la documentación, resolución y análisis técnico de laboratorios de seguridad ofensiva (PortSwigger Web Security Academy). 

Este espacio funciona como una base de conocimientos estructurada para consolidar metodologías de explotación, entender vectores de ataque a nivel de código y estudiar las contramedidas de mitigación asociadas.
